# Bloxo — Google Play store listing

Copy each field into Play Console → **Grow users → Store presence → Main store listing**.
English is the default language. Add the others under **Manage translations → Add your own translations**.

| Field | Limit |
|---|---|
| App name | 30 characters |
| Short description | 80 characters |
| Full description | 4000 characters |

Graphics (all in this folder):
- App icon: `graphics/icon-512.png` (512×512)
- Feature graphic: `graphics/feature-graphic-1024x500.png` (1024×500)
- Phone screenshots: `screenshots/01…08.png` (1080×1920, upload all 8 in order)
- To re-render the screenshots: `tools/make_store_screenshots.sh` (add `ar`, `fr`… for another language)
